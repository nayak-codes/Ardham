Privacy Policy

Telugu Meaning browser extension · Last updated: 17 November 2026

Telugu Meaning shows the Telugu meaning of text you select on a webpage. It does not collect, store, sell or share your personal data. The text you select is sent to a translation service only to get the meaning, and nothing is kept by the developer.

What the extension does

When you select text on a webpage, the extension displays its Telugu meaning in a small tooltip next to your selection. If the selected text is already in Telugu, it shows the English meaning instead.

What data is handled

DataWhyWhere it goes
The text you select To get its meaning Google Translate. If you add your own API key, Anthropic is used instead.
A short sentence around your selection (only for short selections, when you use an API key) To pick the correct meaning for the context Anthropic API
Your settings: API key, model name, auto/button mode To remember your choices Stored only on your device, in the browser's local extension storage

Text is sent only at the moment you select it. The extension does not read or send anything else on the page.

What the developer does not do

  • No personal information is collected.
  • No browsing history, page content, or usage analytics are collected.
  • No data is sent to any server owned by the developer.
  • No data is sold, rented, or shared for advertising, or used to decide creditworthiness or lending.
  • No remote code is downloaded or run. The extension only receives translated text from the services above.

Third-party services

The text you select is processed by the services below, under their own privacy policies:

  • Google Privacy Policy (Google Translate)
  • Anthropic Privacy Policy (only if you enter your own API key)

Your API key

If you choose to enter an Anthropic API key, it is stored only in your browser's local extension storage and is not synced or shared. It is used only to send requests to the Anthropic API. You can remove it any time from the extension's settings page.

Permissions

  • storage: saves your settings on your device.
  • Access to translate.googleapis.com and api.anthropic.com: gets the translation of the selected text.
  • Runs on all websites: lets you select text on any page and see the tooltip.

Children

The extension does not knowingly collect personal information from anyone, including children.
